# Notice

stamp-flow не содержит файлов hh-applicant-tool и не изменяет их. Он использует hh-applicant-tool как внешнюю зависимость: при установке (`pip install`, `docker compose build`) апстрим скачивается из репозитория автора на закреплённом коммите (см. `pyproject.toml`, версия 1.9.2). Во время работы stamp-flow расширяет апстрим в памяти процесса: наследует его класс операции `apply-vacancies`, вызывает его внутренние методы и подключает свои команды и логирование через хуки при запуске (`src/stamp_flow/bootstrap.py`). Исходники апстрима при этом не меняются.

**hh-applicant-tool:** https://github.com/s3rgeym/hh-applicant-tool, © 2023-2026 Sergey M.

У апстрима нет файла LICENSE (GitHub показывает license null). Условия указаны в разделе «Лицензионное соглашение (Limited Non-Commercial License)» его README: личное использование и изучение; публикация и распространение изменённых версий и коммерческое использование без письменного согласия автора запрещены; при любом распространении обязательна ссылка на автора и оригинальный репозиторий.

Лицензия MIT из файла LICENSE относится только к коду stamp-flow. На hh-applicant-tool она не распространяется.

Следствия для пользователей stamp-flow:

- Ставь hh-applicant-tool из репозитория автора (это делают `pip install` и Dockerfile): stamp-flow его не распространяет.
- Не публикуй собранные Docker-образы и копии кода апстрима, в том числе изменённые.
- Не используй связку в коммерческих целях без письменного согласия автора апстрима.
- Код stamp-flow может обновляться отдельно, но он рассчитан на закреплённый коммит апстрима: при смене коммита перепроверь связку.

Это пояснение, а не юридическая консультация. Актуальные условия смотри в README апстрима.
